7.3 Flow Details

Flow 1: Full Pickup
1. Customer places hold (qty=1)
2. Admin resolves as PICKED_UP with fulfilledQty=1
3. Assertions:
- Hold status = PICKED_UP
- SalesHistory row created (qty=1, price=unit)
- Product.heldQuantity returns to baseline
- Product.pickedQuantity += 1

Flow 2: Release
1. Customer places hold (qty=1)
2. Admin resolves as RELEASED with fulfilledQty=0
3. Assertions:
- Hold status = RELEASED
- NO SalesHistory row created (correct — no sale)
- Product.heldQuantity returns to baseline
- Product.available restored

Flow 3: Partial Pickup
1. Customer places hold (qty=2)
2. Admin resolves as PICKED_UP with fulfilledQty=1
3. Assertions:
- Original hold status = PICKED_UP (qty=2, fulfilled=1)
- New ACTIVE hold created (qty=1, same expiration)
- SalesHistory created (qty=1)
- Product.heldQuantity adjusted correctly
- Product.pickedQuantity += 1
